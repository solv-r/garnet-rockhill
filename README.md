# Garnet Rockhill + Rockhill Homes platform

One Next.js project serving the corporate site, the Rockhill Homes property site, and a shared admin, backed by Supabase.

**Start here:** `docs/LOCAL_SETUP.md` (run everything on your PC) > `docs/SUPABASE_TEST_SCRIPT.md` (test it) > `docs/PLACEHOLDER_PHOTOS.md` and `docs/UPDATING_THE_SITE.md` (make it yours) > `docs/DEPLOYMENT.md` (go live).

Quick commands: `npm install` · `npm run dev` · `npm run create-admin` · `npm run typecheck` · `npm test` · `npm run build`

Other docs: ARCHITECTURE, ADMIN_GUIDE, COSTS, MAINTENANCE, TESTING_REPORT, OUTSTANDING_INPUTS, LAUNCH_CHECKLIST.
